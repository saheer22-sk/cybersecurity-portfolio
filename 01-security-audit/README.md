# Cybersecurity Risk Assessment & Security Audit

## Project Overview

This project is a cybersecurity risk assessment and security audit for a fictional company called **NovaMart (Pvt) Ltd**, a small electronics retailer.

I completed this project to practice identifying assets, vulnerabilities, threats, risks, and appropriate security controls.

The project demonstrates how basic cybersecurity principles can be applied to a business environment.

## Scenario

NovaMart has approximately 35 employees and around 5,000 customers.

The company uses:

- Windows computers
- Company Wi-Fi
- E-commerce website
- Customer and order database
- Cloud file storage
- Employee accounts
- Administrator account
- Router and firewall
- CCTV

A security review was conducted after employees received suspicious phishing emails.

## Key Risks Identified

The assessment identified several cybersecurity risks:

- Weak administrator password and no MFA
- Unpatched Windows computers
- Shared Wi-Fi password
- Phishing attacks targeting employees
- Database and backup stored on the same server
- Excessive employee access to cloud files

## Security Controls Recommended

The following controls were recommended:

- Strong password policy
- Multi-Factor Authentication (MFA)
- Regular patch management
- Individual network authentication
- Cybersecurity and phishing awareness training
- Separate and secure backups
- Backup recovery testing
- Principle of Least Privilege (PoLP)
- Regular access permission reviews
